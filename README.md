## 美术重点

| 更新资源 | 方向 |
|---|---|
| FrozenZone | 霜花/覆霜地面，允许落子后触发冰冻 |
| FrozenBlock | 半透明薄冰，保留花色识别与倒计时可读性 |
| GateContact | 木质或黄铜机关座，明确接通/断开状态 |
| GateBar | 花园木闸，与普通栅栏区分 |
| FreezeTime（关联道具） | 统一按钮材质，保留“冻结关卡时间”语义 |

程序需同步调整端子染色、数字样式和开关反馈。当前开门时门栏隐藏，没有独立开启态贴图。
