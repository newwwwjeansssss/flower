# 31—42关：用局部线索引入重叠

2026-10-27 第六版。已写入「花田试玩 · 1–25 / 31–42关」。本版针对“数字格在无辨识度的棋盘内部，没有解题入口”的反馈，重排全部12关的边界、重叠位置及提示栅栏。可视对照见 [关卡总览](overlap-silhouettes.html)。修改前备份位于工作区 `output/overlap-before-local-cues-20261027/`。

## 本版规则

每个重叠点必须有附近的可读起点：起点接触边界或栅栏，从这里能够放下的所有合法花块都必须经过对应数字格。此条件按当前允许旋转、镜像、形状重复使用且每种至少一次的规则枚举；不把标准解块数当库存。

- 31—36：选定起点只有1种合法完整花块摆法，且可继续通关；画完第一块后，经过数字格的第二块候选控制在2—4种。31、32可以通过连续的局部唯一摆法完成。
- 37—42：每个局部起点保留1—3种合法摆法，至少一种可通关。38、40、41的起手花块一次经过两个数字格；42先上方短角，再判断下方转角长短，最后协调连接块。
- 34靠右上外伸短角及内凹台阶提供线索，不加栅栏；其余使用1—3段原有提示栅栏。每段栅栏都排除实际合法几何摆法。
- 保留17—25个有效格、5—8块标准解花块、原有形状组合、单点/双点节奏；全部无封闭内部空洞。每关至少两块普通花块通过两个或更多格子接触重叠核心。
- 33保留用户指定的 `(3,2)`—`(3,3)` 栅栏，另补短槽左侧及数字格左侧的栅栏。坐标均为零基。
- 标准解提示顺序与设计起点对齐，提示按钮先指向该局部入口。没有增加强制手势、额外标记、机关门或冰冻。

## 逐关落笔依据

## 难度与验证边界

本版控制的是“从哪里开始”和起手的局部分支，不能据此断言整关都更简单。部分关卡加入约束后，随意在整盘落子的可续解比例下降，因此不把所有合法首步的比例作为玩家成功率。39关下沿两种起手中有一种会立即耗尽该数字格的后续接法，仍需玩家作局部判断；后段保留试放与调整。真人试玩还需要验证玩家是否会先看见这些入口、是否能顺着已落下的花块继续推理。

`docs/overlap-trial-audit.json` 记录每关完整求解、每个起点的候选/可续解数量、起手后数字格候选、栅栏影响和源文件哈希。`design.entryCells` 与 `design.landmark` 是编辑器设计元数据；试玩只显示真实边界、栅栏和数字格，没有额外起点标记。
